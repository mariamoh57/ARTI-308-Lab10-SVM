### Overview
This assignment implements a **Support Vector Machine (SVM)** classifier to categorize Iris flowers into three species: Setosa, Versicolor, and Virginica. The assignment demonstrates the full machine learning pipeline, from exploratory data analysis to model optimization.

### Key Steps Completed
1. **EDA & Visualization:** Analyzed feature correlations using `pairplot` and `KDE` plots to identify the separability of species.
2. **SVM Implementation:** Built a baseline SVC model using the Radial Basis Function (RBF) kernel.
3. **Hyperparameter Tuning:** Used **GridSearchCV** to find the optimal values for `C` (regularization) and `gamma` (kernel coefficient).
4. **Evaluation:** Achieved high precision and recall, as shown in the classification reports and confusion matrices.
